# Reel-Stil-Leitfaden

Abgeleitet aus fünf Referenz-Reels (Instagram, November 2026). Dieser Leitfaden übernimmt
die Bauweise der Referenzen, nicht deren Inhalte, Marke oder Texte.

## Was die Referenzen sind

- Hochformat 1080×1920, 30 fps, 32–68 Sekunden.
- Zweiteilig: zuerst eine erzählte 3D-Mini-Geschichte (10–45 s), danach ein Werbeblock
  für das Produkt des Erstellers (20–25 s).
- Die Bilder sind keine Ausgaben eines KI-Videomodells, sondern per Code gerenderte,
  einfache 3D-Szenen (Low-Poly-Figuren, klare Formen, flache Texturen).
- Englische Sprecherstimme, durchgehend, ohne Pausen, ca. 3 Wörter pro Sekunde.

## Die Erzählformel (Kern des Stils)

Jede Geschichte ist eine Kette aus Lösung und neuem Problem:

1. **Einstieg in 3 Sekunden:** Situation plus erste, zu einfache Lösung.
   Beispielmuster: „Gestrandet auf einer Insel? Lehn ein paar Palmblätter aneinander, fertig ist das Dach.“
2. **„Aber …“:** Die Lösung scheitert an etwas Konkretem (Regen, Wind, Flut, Hunde).
3. **„Also …“:** Eine sichtbare bauliche Verbesserung behebt genau das.
4. Schritte 2–3 drei- bis fünfmal wiederholen, jede Runde 4–6 Sekunden.
5. **Begriff als Pointe:** Nach manchen Runden fällt das Fachwort als Ein-Wort-Satz
   („Stelzen.“ „Reet.“ „Ein Mittelstreifen.“).
6. **Offenes Ende:** Die Geschichte bricht mit einem neuen Problem oder einer
   Behauptung ab („Die meisten halten die linke Spur für die schnelle. Ist sie nicht.“).

Sprachregeln: Du-Form, Präsens, kurze Hauptsätze, konkrete Zahlen und Materialien,
keine Füllwörter, kein Intro, keine Begrüßung.

## Bild

- Eine Szene, ein Ort, ein Objekt, das sich Schritt für Schritt verändert. Der Zuschauer
  sieht denselben Gegenstand wachsen (Bett → Stelzen → Dach).
- Eine namenlose Figur in einfarbiger Kleidung als Maßstab und Handelnde.
- Kamera: ruhige Halbtotale, pro Runde ein Schnitt oder langsamer Schwenk, dazu einzelne
  Nahaufnahmen für das Detail, das gerade erklärt wird.
- Wetter und Tageszeit als Problemträger: Regen, Nacht, Flut werden sichtbar eingeblendet.
- Warme, satte, leicht entsättigte Farben; pro Reel eine dominante Farbwelt
  (Holzbraun, Bambusgrün, Wüstenbeige).
- Einblendungen im Bild, wenn es etwas zu messen oder zu benennen gibt: Zahlen
  („70 MPH“), Etiketten am Objekt, Pfeile für Kräfte, Stufenmarke oben links („LEVEL 1–4“).

## Untertitel

- Immer nur ein Wort, im Takt der Stimme.
- Position mittig, etwas oberhalb der Bildmitte.
- Fette serifenlose Schrift, weiß mit dunkler Kontur; Schlüsselwörter gelb.

## Ton

- Eine ruhige, sachliche Erzählstimme, nah aufgenommen, kein Sprecherwechsel.
- Keine hörbare Musikdominanz; die Stimme trägt das Reel.

## Abschlussblock der Referenzen (nur zur Einordnung)

Heller Hintergrund, grüne Akzentfarbe, animierte Oberflächen-Kärtchen, Beweiszahlen
(Aufrufe), am Ende die Aufforderung, ein Stichwort zu kommentieren. Das ist Werbung für
ein fremdes Produkt und wird nicht übernommen.

## Mein Stil für künftige Projekte

Übernommen wird die Formel, der Rest ist eigenständig:

| Element | Festlegung |
|---|---|
| Format | 1080×1920, 30 fps, 30–45 s |
| Aufbau | Einstieg (0–3 s), 4–5 Runden „Aber/Also“ (je 5–6 s), offenes Ende (3–4 s), Abspann (3–5 s) |
| Text | Du-Form, Präsens, ca. 2,5–3 Wörter pro Sekunde, 90–120 Wörter gesamt |
| Sprache | Deutsch als Standard, Englisch auf Wunsch |
| Bildwelt | Einfache 3D-Szene, ein Ort, ein Objekt, das mitwächst; eine Farbwelt pro Reel |
| Einblendungen | Stufenmarke oben links, Zahlen und Etiketten am Objekt |
| Untertitel | Ein Wort im Takt, weiß mit Kontur, Schlüsselwort in einer Akzentfarbe |
| Akzentfarbe | Eigene Farbe pro Kanal, nicht das Grün der Referenzen |
| Abspann | Eine Frage oder ein Ausblick auf Teil 2 statt Produktwerbung |

## Vorlage für ein Skript

```
Titel: Wie aus <einfacher Ausgangspunkt> <fertiges Ergebnis> wird
Ort / Farbwelt: …
Figur: …

0–3 s    Einstieg: <Situation>? <erste Lösung>, und du hast <Ergebnis>.
Runde 1  Aber <Problem>. Also <Verbesserung>. [<Begriff>.]
Runde 2  Aber <Problem>. Also <Verbesserung>.
Runde 3  Aber <Problem>. Also <Verbesserung>. [<Begriff>.]
Runde 4  Aber <Problem>. Also <Verbesserung>.
Ende     Aber <das eigentliche Problem> … (offen)
Abspann  <Frage an die Zuschauer>
```

Pro Runde notieren: Kameraeinstellung, was sich am Objekt ändert, welche Einblendung erscheint.
